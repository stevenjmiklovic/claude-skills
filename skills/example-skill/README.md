# example-skill

A minimal template skill that shows how to structure a Claude Code skill.

## Description

This skill serves as a starting point. Copy this directory, rename it, and replace the contents of `instructions.md` with your own domain-specific instructions.

## Usage

Add the contents of [`instructions.md`](./instructions.md) to your project's `.claude/instructions.md`.

## Metadata

See [`skill.yaml`](./skill.yaml) for author, version, and tag information.
